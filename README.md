# Evolve Alerts

App web del equipo de Evolve Digital para recibir en el celular los avisos de Claude Code.

1. Abre la página en Safari (iPhone) o Chrome (Android) y agrégala a la pantalla de inicio.
2. Ábrela desde el ícono, activa las notificaciones y copia tu código.
3. Pega el código en el instalador de avisos de tu PC.

La página no tiene servidor: tu PC firma cada aviso y lo manda directo al servicio de notificaciones
de Apple o Google. Aquí sólo vive la llave pública; la privada se queda en cada PC.
